# Six Words, One Story

A complete story in exactly six words, written by `main.ts` to `/output/entry.txt` for the [Six Words, One Story](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410) bounty on make.fun.

## The entry

> Married her. Buried her. Never left.

Six words, 36 characters. A whole life in three beats: marriage, loss, and the devotion that outlives both. The last two words turn the burial from an ending into a promise — he stayed.

## How to run

Requires Node 22 or later (the program is plain TypeScript run as-is):

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` validates the story first (exactly six words, 1–60 characters) and then writes it to `/output/entry.txt`.
